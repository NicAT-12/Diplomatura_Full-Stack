# Desarrollo en React

## Descripción

Esta carpeta reúne todo el recorrido de la Diplomatura Full-Stack correspondiente al desarrollo con **React**, desde los fundamentos de HTML/CSS/JavaScript hasta la construcción de una aplicación integradora con backend en Firebase. Está organizada por módulos, cada uno con sus propias tareas y su README detallado.

---

## Contenido

### 📁 [Módulo 1](./Modulo%201) — Fundamentos de HTML, CSS, JavaScript y React

Bases del desarrollo web: maquetación semántica, estilos, manipulación del DOM, formularios, programación orientada a objetos, asincronismo y los primeros componentes en React.

* Tarea 1 - HTML y CSS
* Tarea 2 - JavaScript esencial
* Tarea 3 - JavaScript avanzado
* Tarea 4 - React inicial

### 📁 [Módulo 2](./Modulo%202) — Hooks, Consumo de APIs, Enrutamiento y Eventos

Manejo de estado con Hooks y hooks personalizados, consumo de APIs REST, enrutamiento con React Router (rutas dinámicas, anidadas y protegidas) y manejo de eventos del DOM en formularios controlados.

* Tarea 1 - Hooks
* Tarea 2 - API Rest
* Tarea 3 - Enrutamiento
* Tarea 4 - Eventos

### 📁 [Módulo 3](./Modulo%203) — Firebase y React Avanzado

Integración de React con Firebase: configuración segura del SDK, operaciones CRUD y lecturas en tiempo real con Firestore, autenticación, reglas de seguridad, y manejo de estado global con Context API.

* Tarea 1 - Firebase Parte 1
* Tarea 2 - Firebase Parte 2
* Tarea 3 - React Avanzado

### 📁 [Trabajo Integrador Final](./Trabajo%20Integrador%20Final) — Mis Películas Favoritas

Aplicación CRUD completa para gestionar una colección de películas favoritas, integrando todo lo aprendido en los módulos anteriores: React Router, Firebase Firestore, formularios controlados, manejo de estados de carga/error y diseño con Tailwind CSS.

---
