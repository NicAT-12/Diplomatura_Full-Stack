# Diplomatura Full-Stack

¡Bienvenido a mi repositorio de la Diplomatura Full-Stack!

En este espacio voy documentando mi proceso de aprendizaje y crecimiento como desarrollador, incorporando proyectos, prácticas y actividades realizadas a lo largo de la cursada.

## Contenido

El repositorio está organizado por curso/tecnología, y dentro de cada uno por módulos con sus respectivas tareas y proyectos.

### ✅ [Desarrollo en React](./Desarrollo%20en%20React)

* **Módulo 1** — Fundamentos de HTML, CSS, JavaScript y React.
* **Módulo 2** — Hooks, consumo de APIs, enrutamiento y eventos.
* **Módulo 3** — Firebase (configuración, CRUD, autenticación) y React avanzado (Context API).
* **Trabajo Integrador Final** — Aplicación CRUD "Mis Películas Favoritas", con Firestore y React Router.

### ✅ [Desarrollo en Angular](./Desarrollo%20en%20Angular)

* **Módulo 1** — Conociendo Angular (Angular CLI, signals, interpolación y event binding), directivas y formularios reactivos, servicios y pipes (estándar y personalizados) y routing avanzado (lazy loading, rutas dinámicas y `localStorage`), con estilos en TailwindCSS.
* **Trabajo Integrador Final** — "Biblioteca Abierta", aplicación web multisitio para explorar libros con la API de Open Library, con búsqueda, filtros, detalle dinámico y favoritos.

### ✅ [Desarrollo en NodeJS](https://github.com/NicAT-12/Diplomatura_Full-Stack/blob/main/Desarrollo%20en%20NodeJS)

- **Tarea 1** — Introducción a Node.js: primer script con el módulo nativo `os` y un módulo propio (CommonJS).
- **Tarea 2** — Mi primera API REST con Express: gestión de un recurso de libros con rutas GET, POST, PUT y DELETE, probada con Postman.
- **Tarea 3** — API de Tareas con Express y Mongoose: CRUD completo sobre MongoDB Atlas con validación de esquema.
- **Tarea 4** — Integración Front-Back: gestor de tareas con frontend en React (Vite, TailwindCSS y `fetch`) conectado a la API, desplegado en Firebase Hosting y Render.
- **Trabajo Integrador Final** — "Node Clon Chat", API REST para un clon de chat 1 a 1 con Node.js, Express y MongoDB (usuarios, chats y mensajes), con autenticación JWT, validaciones con Zod, paginación y búsqueda de mensajes, y frontend en React, desplegado en Render y Vercel.

---

Cada curso cuenta con su propio README de índice, y cada módulo/tarea con su propio README detallando consigna, tecnologías, funcionalidades e instalación.

## Objetivo

El objetivo de este repositorio es registrar mi evolución como desarrollador Full Stack, consolidar conocimientos mediante proyectos prácticos y construir un portfolio técnico que refleje las habilidades adquiridas durante la diplomatura.
